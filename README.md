# EarnWise ⚡

### Micro-Investment & Savings Platform for Gig Workers

> **Your income changes every day. Your financial plan should too.**

## 🎯 Problem Statement

Gig workers have irregular income and often lack automatic savings, tax planning, and simple investment tools. Deciding how much to save or invest after every payout also creates decision fatigue.

## 💡 Solution

EarnWise is an intelligent financial platform for gig workers that automatically analyzes incoming payouts and allocates a safe portion toward:

* Emergency Savings
* Tax Reserve
* Micro-Investments
* Daily Expenses

It uses a **30-day income average** and adaptive income tiers while maintaining a **₹5,000 minimum balance floor**.

## 🚀 Key Features

## 🧠 Core Decision Logic

| Income Level    | Auto-Save |
| --------------- | --------: |
| Slump < 60%     |        0% |
| Lean 60–100%    |        5% |
| Normal 100–150% |    10–12% |
| Peak > 150%     |       15% |

Additional safeguards:

* Minimum balance: **₹5,000**
* Monthly savings ceiling: **₹8,000**
* Tax provisioning: **10% per payout**
